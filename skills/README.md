# Skills

One skill, `ukisai-benchmarks`. It teaches your agent how to set up, run, monitor and report every benchmark in this repo.

## Claude Code

```bash
python skills/install.py --claude
```

## Codex

```bash
python skills/install.py --codex
```

With no flag it installs for whichever of `claude` / `codex` is on your PATH. Rerun after `git pull` to update.
